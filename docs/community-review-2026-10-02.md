## 1. 지금 활성화된 KBL 팬 커뮤니티

| 곳 | 성격 | 메모 |
|---|---|---|
| 디시인사이드 **농구 갤러리**(농갤) | 국내 농구에서 가장 활발 | 자유로운 분위기, 거친 글도 많음 (나무위키 "농구 갤러리") |

| 구단별 팬카페·인스타그램 | 팀 단위 | 이번 조사에서 규모 확인 못 함 |

세션 환경에서 mania.kr·다음 카페는 접속 차단 → 검색 결과 요약으로만 확인. 에펨코리아·더쿠 등 종합 커뮤니티의 농구 게시판 활성도는 확인 못 함.

**정리**: 수다(이야기)할 곳은 이미 있다(농갤·매니아). 그런데 그 어디에도 "기록을 보면서 같이 얘기하는" 곳은 없다 — 기존 커뮤니티는 기록 화면이 없고, 우리는 대화가 없다. 우리가 노릴 빈자리는 **"데이터에 붙은 대화"**이지, 두 번째 농갤이 아니다.

## 2. 커뮤니티로 가는 단계 제안

### 먼저 알아야 할 현실: 빈 게시판 문제
- 인터넷 커뮤니티는 보통 **100명 중 1명이 글을 쓰고, 9명이 반응하고, 90명은 보기만** 한다(90-9-1 법칙).
- 우리 예상 규모(동시 접속 수십~수백)면 글 쓰는 사람이 하루 몇 명 → 자유게시판을 열면 "글 3개짜리 빈 방"이 된다. 빈 방은 사람을 쫓아낸다.
- 그래서 **게시판부터 만들지 말고, 클릭 한 번으로 참여할 수 있는 것부터** 만든다.

### 0단계 — 지금 구조 그대로 (DB·로그인 없음)
기존 커뮤니티를 "경쟁자"가 아니라 "유입 통로"로 쓴다.
- **공유 미리보기(OG 이미지)**: 선수 카드·54-0 결과 링크를 농갤·매니아·카톡에 붙이면 카드 그림이 바로 뜨게. 지금은 이미지 저장만 있음
- 선수·시즌 주소를 "짤"처럼 쓰기 좋게: 비교 링크(`/compare?a=…&b=…`)를 글에 붙이면 미리보기에 두 선수가 보이게
- 효과 측정: Vercel Analytics(무료)로 어디서 들어오는지(referrer) 본다 → 실제로 농갤·매니아에서 오는지 확인

### 1단계 — 로그인 없는 가벼운 참여 (작은 저장소 하나 필요)
- **투표**: "이번 라운드 MVP", "역대 최고 포인트가드" — 우리 기록 카드를 보기로 보여 줌
- **경기 예측**: 오늘 경기 승자 맞히기 → 다음 날 결과·적중률 (경기 목록은 이미 수집 중)
- **카드 반응**: 선수 카드에 👍 같은 반응 수
- 필요한 것: Vercel KV / Upstash Redis 같은 무료 키-값 저장소, 같은 사람 중복 방지(쿠키+IP 정도 — 완벽하진 않음)
- 장점: 글을 안 써도 참여, 욕설·관리 부담 거의 없음

### 2단계 — 구글 로그인 (CLAUDE.md "후속 예정"에 이미 있는 일)
- **닉네임 + 응원팀 배지**: 커뮤니티 정체성의 시작. 응원팀 색이 이름 옆에
- **선수·경기 페이지에 붙는 댓글**: 자유게시판이 아니라 "이 선수 카드", "이 경기"에 달리는 댓글 → 글거리가 데이터에서 자동으로 생김
- 즐겨찾기를 계정으로 옮기기, 54-0 기록 랭킹, 위클리 판타지(docs/fantasy-review-2026-10-02.md 안 A·B)
- 필요한 것: Auth.js(구글) + DB(Supabase 등) + 아래 "기본 설정"

### 3단계 — 게시판
- 2단계 댓글이 **하루 수십 개를 꾸준히** 넘을 때만. 처음엔 "자유" 하나 + 팀별 말머리(필터)로 시작, 팀별 게시판 10개로 쪼개지 않는다(쪼개면 전부 빈 방)

### 사람이 글을 쓸 수 있게 되는 순간(2단계) 반드시 필요한 기본 설정
| 항목 | 왜 |
|---|---|
| 이용약관·개인정보 처리방침·탈퇴(데이터 삭제) | 구글 로그인으로 이메일을 받는 순간 개인정보 처리자가 됨 |
| 신고 버튼 + 신고 N회 자동 숨김 | 운영자 1명이 모든 글을 볼 수 없음 |
| 금칙어·욕설 필터, 글쓰기 속도 제한 | 도배·광고 봇 |
| 운영자 화면(숨김·삭제·차단) | 문제 생겼을 때 바로 대응 |
| 명예훼손·권리침해 글 요청 시 임시 조치 절차 | 선수 비방 글은 농구 커뮤니티의 단골 문제. 법적 의무 범위는 사업화 검토 때 변호사 확인 항목에 추가 |
| 운영 원칙 한 장(선수 인신공격·성희롱·지역 비하 금지) | 처음 문화가 끝까지 간다 |
| 비용 | Supabase·Vercel 무료 구간으로 시작 가능. 사람이 늘면 유료 전환 |

KBL 약관(제23·28조)은 "기록을 영리 목적으로 쓰지 말라"는 것이라 비영리 커뮤니티 자체는 걸리지 않지만, 커뮤니티가 커져 광고를 붙이고 싶어지는 순간 KBL 서면 승낙 문제가 다시 나온다.

## 3. 스탯을 줄이고 커뮤니티로 가야 하나?

**권장: 스탯은 줄이지 말고, "앞에 내세우는 것"만 바꾼다.**

이유
1. **스탯이 사람이 오는 이유다.** 농갤·매니아는 이미 크고, 거기서 대화하던 사람이 굳이 우리에게 올 이유는 "거기엔 없는 기록 화면"뿐이다. 스탯을 줄이면 작은 농갤이 된다.
2. **스탯이 대화거리를 만든다.** 빈 게시판 문제의 해답은 "매일 새로 생기는 이야깃거리"인데, 우리는 매일 새벽 자동으로 갱신되는 기록이 있다(시즌 하이, 이정표 달성, 순위 변동).
3. **유지 비용이 거의 0이다.** 수집·가공은 Actions가 매일 자동으로 한다. 줄여도 아끼는 일이 별로 없다. 반대로 커뮤니티는 매일 사람 손(관리)이 든다.

대신 바꿀 것
- **메뉴·홈 정리**: 자주 안 쓰는 깊은 기능(허슬 부문, CSV, 슛 구역 성공률 부문 등)은 지우지 말고 한 단계 안쪽으로. 홈은 "기록 요약" → "오늘의 이야깃거리"(어젯밤 시즌 하이, 이정표 달성, 오늘 투표·예측)로
- 새 기록 기능 추가는 당분간 멈추고, 커뮤니티 0~1단계에 힘을 쓴다
- 판단 지표: 0단계 뒤 한 달 동안 외부(농갤·매니아·카톡)에서 들어온 방문이 꾸준히 있으면 1단계, 1단계 투표 참여가 하루 수십 건이면 2단계
