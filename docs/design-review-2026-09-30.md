# 디자인 점검 2026-09-30 — 진단과 반영 계획

> `.claude/design-rules.md`의 4단계 절차를 따른 기록. 반영 결과는 PLAN.md §7과 세션 로그에 남긴다.

## 1단계 — 목적 분석
- 제품 유형: **데이터 대시보드 + 매거진형 팬페이지** (내부 도구 아님, 랜딩도 아님). 팬이 시즌 중 반복 방문한다.
- 사용자·빈도: KBL 팬, 대부분 폰. 경기 다음날 "누가 잘했나"를 보러 오는 반복 방문.
- 기존 자산: 운영 중(Vercel 배포). Next.js 15 + Tailwind v4 + Recharts. **재작성 금지, 있는 것을 다듬는다.**
- 제약: 정적 사이트, 차트 라이브러리 추가 금지, KBL 이미지 핫링크(로드 실패 대비 필수), 라이트/다크 둘 다.

## 2단계 — 보유 스킬 확인
- 계정 스킬: `dataviz`, `humanizer`
- 프로젝트 스킬(`.claude/skills/`, 77개): 대부분 랜딩용 테마(WebGL·글래스·레이저 등)라 대시보드에는 부적합. 아래만 후보.

## 4단계 — 진단 (2026-09-30 빌드, 390px·1280px 스크린샷 기준)

### A. 구조 문제 (사용자 지적 + 실측)
| # | 문제 | 실측 | 처방 |
|---|---|---|---|
| A1 | **표가 가로 스크롤** (순위표·선수 기록표·비교표) | 390px에서 표 영역이 옆으로 밀림. 사용자: "UX를 해친다" | 모바일은 표 대신 **행 카드**: 순위·아바타·이름/팀·선택 부문 값(크게)·보조값 3개. 행을 누르면 그 자리에서 펼쳐져 전 항목이 2열 격자로. PC(≥1024px)만 전체 표. 가로 스크롤 요소 0개가 완료 기준 |
| A2 | **필터 칩 과다** | 순위표 모바일: 콘텐츠 전에 컨트롤 6줄(부문·경기당·포지션·국적·팀·표본). 선수 탭 5줄. 팀 분포 4줄 | **1차 컨트롤 하나만 노출**(순위표=부문 칩, 선수 탭=검색+시즌, 팀 분포=지표+팀 범례). 나머지는 "필터" 버튼 → 모바일 바텀시트 / PC 인라인 패널. 적용 중인 필터는 요약 칩("가드 · 국내 ✕")으로 한 줄. 표본 기준은 필터 안 고급 항목으로 |
| A3 | **페이지가 너무 김** | 순위표 8,314px(142행 전부), 선수 탭 16,903px(193장 전부) | 25행 / 20장 먼저, "더 보기" 버튼. 주소에 개수 안 남김 |
| A4 | **검색창 중복** | 선수 탭에 상단 검색 + 본문 큰 검색 두 개 | 선수 탭에서는 상단 검색 숨김(본문 큰 검색이 그 역할). 다른 탭은 상단 검색 유지 |
| A5 | 시즌 선택 중복 | 상단 시즌 드롭다운 + 선수 탭 본문 시즌 칩 | 선수 탭 본문 시즌 칩 제거, 상단 드롭다운만 |
| A6 | 설명 문단이 제목마다 붙음 | "부문을 고르면 1~3위가 위에…", "점 하나가 선수 한 명입니다…" 등 | 제목 아래 설명은 **한 줄 이하**, 나머지는 ⓘ 툴팁 또는 용어 탭 링크. 자명한 설명은 삭제 |
| A7 | 홈 "더 보기" 6칸 동일 카드 | 3-등분 동일 카드 패턴(안티 슬롭 B) | 큰 버튼 2개(선수·순위표) + 작은 링크 줄(팀 분포·비교·용어) 비대칭. "플레이어 카드 보기" 문구 → "선수 카드 보기" |

### B. 타이포·색·표면 (redesign 감사표)
| # | 문제 | 처방 |
|---|---|---|
| B1 | 시스템 기본 폰트, 숫자가 비례폭 | **Pretendard Variable**(한글 최적, jsDelivr CDN, `font-display: swap`) + 숫자 전부 `tabular-nums`. 폰트 하나만 |
| B2 | 위계가 평평함(h2가 14~16px, 본문과 같음) | 단계 고정: h1 28/32px, h2 20/22px, 본문 15/16px, 보조 13px. 단계 간 ≥1.25배 |
| B3 | 모서리 반경 혼재(rounded-xl/2xl/3xl/full) | 3단계만: 컨테이너 16px, 내부 카드 12px, 칩·배지 8px(pill 금지, 아바타는 원). 안쪽 = 바깥 − 패딩 |
| B4 | 회색 계열·그림자 제각각 | 그림자는 카드 1종(`0 1px 2px` + hairline). 회색은 zinc 한 계열. 액센트는 팀 색 외 **하나**(현재 파랑 유지) |
| B5 | 등급 색(S 금색 등)·메달·순위 강조가 팔레트처럼 늘어남 | S만 금색, A~B 팀 색, C 이하 무채색은 유지하되 채도 −20%. 등급 글자는 항상 라벨과 함께(색만으로 정보 전달 금지) |

### C. 인터랙션·접근성 (ui-ux-pro-max)
| # | 문제 | 처방 |
|---|---|---|
| C1 | 칩 높이 36px(h-9) → 터치 타겟 44px 미달 | 칩 h-10(40) + 상하 여백으로 44 확보, 표 행 최소 48px |
| C2 | 포커스 링·호버 일관성 미확인 | 모든 버튼·칩·행에 `focus-visible` 링, 호버는 `transition-colors duration-200`만(`transition-all` 금지) |
| C3 | 로딩·빈 상태 | 시즌 전환 fetch 중 스켈레톤(레이아웃 모양 그대로), 필터 결과 0명 빈 상태 문구 |

### D. AI 티 스캔(kill-ai-slop) 84건 분류
- **고칠 것**: 12번 평평한 위계(12건, B2로 해결), 19번 pill 남발(칩·배지 24건, B3), 21번 반경 불일치(27건, B3), 10번 kicker(영문 이름 uppercase tracking 2건 → 소문자 유지·자간 제거), 22번 테두리·반경 불일치 3건.
- **의도한 것(유지)**: 06번 카드 상단 팀 색 그라데이션(팀 색 → 어둡게, 팬 카드의 핵심 정체성), 11번 큰 숫자 헤드라인(스탯 타일), 13번 비교표 색 점(범례), 24번 SVG 3종(돋보기·메달·실루엣). 유지 항목은 소스에 `deslop-ignore-next-line NN` 주석.

## 반영 순서 (redesign 우선순위 + 사용자 요청 우선)
1. **A1 표 → 행 카드** (사용자 최우선) · A3 더 보기
2. **A2 필터 시트** · A4·A5 중복 제거 · A6 문구 정리 · A7 홈
3. B1 폰트·숫자 → B2 위계 → B3 반경·B4 그림자 → B5 등급 색
4. C1~C5 접근성·상태
5. D 스캔 재실행, 남은 건수와 유지 사유 기록

완료 기준: 390px에서 `scrollWidth`가 화면 폭과 같고 **가로 스크롤 가능한 요소가 0개**(`el.scrollWidth > el.clientWidth`인 요소 검사), 첫 화면 세로 길이 순위표 ≤ 3,000px·선수 탭 ≤ 3,000px, 라이트·다크 스크린샷 4벌, 스캔 잔여 건은 전부 유지 사유 있음.

### 측정 (next build + start, Playwright 크로미움)
- 문서 폭: 8개 화면 × 390·1280 전부 `scrollWidth === innerWidth`. PC 표 폭: 1024·1280에서 순위표·기록표 990/990px.
- 첫 화면 세로(390px): 순위표 8,314 → **2,472px**, 1997 시즌 순위표 → 2,452px, 선수 탭 16,903 → **2,256px**. 홈 1,389, 팀 분포 2,241.
- 가로로 넘치는 요소: **표·카드 0개.** 남은 것은 의도한 칩 줄(순위표 부문 칩, 선수 상세 카드 시즌·비교 시즌 칩, 비교 탭 A·B 시즌 칩, 홈 부문별 1~3위 카드 줄)과 Recharts 내부 요소(`ResponsiveContainer`의 폭 0 래퍼 `div`·회전한 축 제목 `text`, overflow visible이라 스크롤되지 않음).
- 동작: 행 두 개 동시 펼침(14항목 격자), 더 보기 25→50행, 시트 열림·Tab 40번 눌러도 시트 안·가드+국내 적용(주소 `?origin=dom&pos=g`, 49명)·요약 칩 ✕ 해제·ESC·바깥 누르기 닫힘·스크롤 잠금 해제, 부문 변경 시 25행으로 리셋, 선수 탭 상단 시즌 2008-09 선택 → 그리드 165명·20장, PC 인라인 패널(대화상자 아님)·ESC. 콘솔 에러 0(이 세션 환경이 kbl.or.kr 차단이라 공식 사진·로고 로드 실패는 제외하고 셈).
