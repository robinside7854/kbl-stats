# 스포츠 앱 UX 비교 — 우리 사이트에 가져올 만한 것 (2026-10-14)

조사 방법: 유아이볼(uibowl.io) MCP 로 스포츠 앱 화면을 찾았어요. 토스 검토(2026-10-08)의 2차예요.

**한계부터 적어 둘게요.**
- 유아이볼에 들어 있는 스포츠 앱은 **KBO STATS**(KBO 공식 기록 앱, 2025-09 수집, 37묶음)와 **레사모**(해외 축구 커뮤니티 앱의 라이브스코어, 2026-02 수집) 두 개뿐이었어요. NBA·ESPN·FotMob·쿠팡플레이·네이버 스포츠는 없었어요.
- 무료 등급은 검색마다 결과 3개, 하루 10번까지예요. 이번에 10번을 다 썼어요.
- 그래서 **2장**은 유아이볼에서 실제로 본 화면이고, **3장**은 해외 스포츠 앱(NBA·ESPN·FotMob 등)에서 흔히 쓰는 방식을 일반 지식으로 적은 거예요. 3장은 유아이볼 근거가 없어요.

## 1. 스포츠 앱에서 반복해서 보이는 원칙

| 원칙 | 스포츠 앱 모습 | 우리 사이트 지금 |
|---|---|---|
| "내 팀" 이 출발점 | KBO STATS 는 맨 위에서 응원팀을 고르면 그 팀 일정·순위·뉴스가 한 화면에 모임("마이팀") | 응원팀은 일정 필터·홈 경기 순서·알림에만 쓰임. 한 화면에 모이지는 않음 |
| 날짜를 옆으로 넘기기 | KBO STATS 마이팀 위쪽에 날짜 칸이 가로로 이어지고 칸마다 상대·결과(5-3, 1-11) | 일정은 세로 목록 + 달 칩 |
| 순위표는 숫자 열이 촘촘 | 경기·승·패·무·승률·게임차·최근10G("6W-4L")·연속("3승") 한 줄 | 거의 같음(최근 5·연승 연패 있음) |
| 순위표 옆 탭 "팀간 전적" | 순위 / 팀간전적 / 투수·수비 / 타자·주루 탭 | 팀 간 상대 전적 없음 |
| 달력으로 보는 일정 | 레사모: 한 달 달력 칸마다 그날 경기 팀 로고 | 달 칩 → 날짜별 목록 |

## 2. 유아이볼에서 본 화면에서 가져올 후보

### A. 작고 바로 효과 있는 것

1. **팀 간 상대 전적 표** (KBO STATS "팀간전적" 탭)
   - 팀 화면 "표" 보기 옆에 탭 하나 더 — 10×10 칸에 "3승 1패".
   - 데이터: 있어요. 경기 결과(games.json)는 30개 시즌 전부라 옛 시즌도 됨.
   - 팀 페이지에는 "상대 팀별 전적" 한 줄 목록으로도 쓸 수 있어요.
2. **일정 위 달력 띠** (레사모 달력)
   - 달을 고르면 위에 그 달 날짜 칸(작게) + 경기 있는 날 점. 누르면 그날로 이동.
   - "내 응원팀" 일 때는 칸에 상대 팀 로고 + 승/패 색 테두리.
   - 데이터: 있어요. 지금 "지난 경기 접기"와 같이 써도 됨.

### B. 중간 크기

3. **팀 페이지 맨 위 "경기 띠"** (KBO STATS 마이팀 날짜 칸)
   - 팀 페이지 머리말 바로 아래에 지난 3경기 결과 + 다음 2경기를 가로로. 칸을 누르면 박스스코어 팝업.
   - 홈에서 로그인 회원 응원팀이 있으면 같은 띠를 보여 줘도 됨(지금 "내 응원팀 경기를 맨 앞에"보다 한눈에 들어옴).
   - 데이터: 있어요.
4. **내 팀 모아 보기** (KBO STATS 마이팀)
   - 응원팀 하나를 고르면 순위·경기 띠·주요 선수 기록·하이라이트·알림이 한 화면에.
   - 지금은 팀 페이지가 사실상 그 역할이라, 4번은 "팀 페이지 + 3번 경기 띠 + 이번 시즌 팀 내 득점 1~3위"로 충분해요. 새 메뉴는 안 만드는 게 좋다고 봐요.

## 3. 해외 스포츠 앱에서 흔한 방식 (유아이볼 근거 없음 · 일반 지식)

5. **선수 페이지 "최근 경기" 표** (NBA·ESPN 선수 화면)
   - 최근 5경기: 날짜·상대·득점·리바·어시·결과. 시즌 평균 아래에 있어 "요즘 폼"이 보임.
   - 데이터: 지금 시즌(26-27)과 25-26 은 박스스코어가 있어 가능. 옛 시즌은 없음 → 시즌을 고르면 숨김.
6. **경기 팝업 "팀 비교 막대"** (ESPN·FotMob 경기 화면)
   - 박스스코어 위에 두 팀 리바운드·어시스트·3점·턴오버·야투%를 가운데 기준 좌우 막대로.
   - 데이터: 있어요(박스스코어 합계). 지금 "이 경기 포인트" 한두 줄 바로 아래가 자리.
7. **쿼터별 점수** (거의 모든 농구 앱)
   - 경기 카드·팝업에 1Q~4Q 점수표.
   - 데이터: **없어요.** 서버 C 경기 상세(`/match/{gmkey}`)에 있다는 건 확인했지만 수집 안 함 → 수집부터 새로 해야 함(경기당 1번 요청).

## 4. 가져오지 않는 게 나은 것

- **실시간 점수**(라이브스코어): 하루 한 번 모으는 구조라 안 맞아요. SCOPE 의 "실시간 금지"와도 충돌.
- **뉴스 탭**(KBO STATS): 기사 저작권·수집 부담이 커요.
- **KBO STATS 메뉴 격자 화면**: 아이콘 8개 격자는 메뉴가 6개인 우리에겐 단계만 늘어요.

## 5. 이미 스포츠 앱처럼 하고 있는 것

- 순위표 최근 경기·연승 연패, 박스스코어 정렬, 경기 카드 홈/원정 좌우 점수판, 하이라이트 영상, 일정 "내 응원팀만", 알림(경기 날 안내·결과).

## 진행 (2026-10-14)

1(상대 전적)·3(팀 페이지 경기 띠)·5(선수 최근 경기)를 만들었어요. 2·4·6·7 은 남은 후보.

## 추천 순서

1. **A-1 팀 간 상대 전적**, 2. **B-3 팀 페이지 경기 띠**, 3. **5 선수 최근 경기** — 셋 다 이미 있는 데이터로 되고, 팬이 자주 찾는 정보예요.
그다음 A-2 달력 띠, 6 팀 비교 막대. 7 쿼터 점수는 수집을 새로 해야 해서 맨 뒤.
