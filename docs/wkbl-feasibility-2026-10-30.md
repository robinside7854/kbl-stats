# WKBL(여자프로농구) 대시보드 가능성 점검 — 2026-10-30

조사 방법: 작업 환경에서는 wkbl.or.kr 이 막혀 있어 GitHub Actions 조사 4번(`claude/probe-wkbl` 브랜치, 응답 표본 포함 — 확인 뒤 지워도 됨)으로 공홈 화면·데이터 주소를 직접 열어 봄.

## 한 줄 결론
기술적으로는 KBL 대시보드의 대부분(선수·팀·시즌 순위·역대 기록·박스스코어·위닝샷 일부)을 만들 수 있다. 다만 **WKBL 은 robots.txt 로 모든 자동 수집을 거부하고, 선수 사진·팀 로고의 무단 사용을 명시적으로 금지**하고 있어, 만들기 전에 WKBL 에 허락을 구하는 것을 권한다.

## 걸리는 것
1. **robots.txt `Disallow: /`** — "자동 수집 프로그램은 들어오지 말라"는 뜻(법 조항은 아니지만 사이트 뜻이 분명함). KBL 때와 가장 큰 차이.
2. **사진·로고 금지 문구** — 모든 화면 하단: "WKBL 소속 6개 구단의 팀로고 … 소속선수의 사진, 초상 … 무단으로 사용할 경우 상표법 및 저작권법에 의해 금지". → 공식 사진·로고는 쓰지 말고 팀 색 + 이니셜 대체 디자인만.
3. 이용약관: KBL 과 같은 "영리 목적 복제·배포 금지" + "게시물이 다른 사이트에서 사용 또는 인용되는 것은 금지" 문구.
4. HTML 을 읽는 방식이라 공홈 화면이 바뀌면 수집이 깨질 위험이 KBL 보다 크다.

## 제안
- 먼저 WKBL(홈페이지 CONTACT US)에 비영리 팬 사이트로 기록을 하루 1회 받아 써도 되는지 묻는다. 허락이 오면 시작.
- 만든다면 이 KBL 사이트와 **따로**(새 저장소·새 주소) — 데이터 받는 방식이 완전히 달라서. 화면·계산 코드는 이쪽 것을 옮겨 쓴다.
- 1차 범위: 박스스코어로 만든 시즌 기록·리더보드·선수 페이지·팀 순위·일정 → 2차: 문자중계 범위 확인 후 클러치·위닝샷, 슛 위치 확인 후 슛 차트.
