HTTP 오류 404.11 - Not Found

이중 이스케이프 시퀀스가 포함된 요청을 거부하도록 요청 필터링 모듈이 구성되어 있습니다.

가능성이 높은 원인:

  • 요청에 이중 이스케이프 공격이 포함되어 있고 웹 서버에서 이중 이스케이프 공격을 거부하도록 요청 필터링이 구성되어 있습니다.

가능한 해결 방법:

  • applicationhost.config 또는 web.confg 파일에서 configuration/system.webServer/security/requestFiltering@allowDoubleEscaping 설정을 확인하십시오.

자세한 오류 정보:

모듈   RequestFilteringModule
알림   BeginRequest
처리기   ExtensionlessUrlHandler-Integrated-4.0
오류 코드   0x00000000
요청한 URL   https://www.wkbl.or.kr:443/static/js/lib/+ path +
실제 경로   D:\wkbl2017\static\js\lib\+ path +
로그온 방법   아직 결정되지 않음
로그온 사용자   아직 결정되지 않음

추가 정보:

이것은 보안 기능이므로 변경 가능한 범위를 완전히 파악하지 못한 경우에는 변경하지 마십시오. 이 값을 변경하기 전에 해당 요청이 악의적이지 않다는 것을 확인하기 위해 네트워크 추적을 수행해야 합니다. 서버에서 이중 이스케이프 시퀀스를 허용하려면 configuration/system.webServer/security/requestFiltering@allowDoubleEscaping 설정을 수정하십시오. 악의적인 사용자가 서버에 보낸 잘못된 형식의 URL 때문에 이 오류가 발생할 수 있습니다.
